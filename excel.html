Quick Attendance

Excel add-in

Take attendance inside Excel.

The add-in puts a Take Attendance button on Excel's Home tab. Pick the way that suits you.

Everyone at the university Recommended

Your IT team installs it once in Microsoft 365, and the button appears in every faculty member's Excel on Windows, Mac and the web. Teachers install nothing.

  1. Download the add-in file below and send it to IT.
  2. IT opens admin.microsoft.com → Settings → Integrated apps → Upload custom apps.
  3. App type Office Add-in, upload the file, assign it to faculty, then Finish deployment. It can take up to a day to appear.

Excel on Windows, just me

  1. Download the installer and double-click it.
  2. If Windows says Windows protected your PC, click More info → Run anyway.
  3. Close Excel completely, open it again, and look for Take Attendance on the Home tab.

Works with Microsoft 365, Excel 2019 and Excel 2021.

Excel on the web

  1. Download the add-in file.
  2. In Excel on the web, open a workbook, then Home → Add-ins → More Add-ins → My Add-ins → Upload My Add-in, and choose the file.

Excel on Mac

  1. Download the add-in file.
  2. In Finder, choose Go → Go to Folder and open ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef (create the wef folder if it is missing).
  3. Move the file into that folder, restart Excel, then choose Home → Add-ins → Quick Attendance.

Prefer no install at all? Use the web app. It works with the same Excel files, on computers and phones. Privacy
